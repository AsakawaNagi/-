## 第一题需求（基础版 Floyd）

**任务目标**：给定图的邻接矩阵，输出指定 m 对节点间的**最短路径长度**

###  输入要求：

- 一个整数 `n`：节点个数，`n < 100`
- 接下来 `n` 行 `n` 列邻接矩阵（值为 `10000` 表示无边）
- 一个整数 `m`：查询对数，`m < 100`
- m 行：每行两个不同的点 `u v`

### 输出要求：

- 输出每对 `(u, v)` 节点的最短路径长度（仅长度，不是路径）

###  需求分解：

| 模块           | 功能                        |
| -------------- | --------------------------- |
| 数据输入模块   | 读取 n，邻接矩阵，m 对点    |
| Floyd 核心模块 | 三重循环实现最短路径更新    |
| 查询处理模块   | 对于每对点输出 `dist[u][v]` |



## 第二题需求（路径恢复版 Floyd）

> **任务目标**：给定图的邻接矩阵，输出指定 m 对节点间的**最短路径的实际路径**

###  输入要求：

同上

###  输出要求：

- 对于每一对节点 `(u, v)`，输出它们之间的最短路径上的所有节点编号，**一行一个**，**按顺序从 u 到 v**

###  需求分解：

| 模块           | 功能说明                                                     |
| -------------- | ------------------------------------------------------------ |
| 数据输入模块   | 同上                                                         |
| Floyd 主体算法 | 不仅更新距离 `dist[i][j]`，还要更新路径前驱矩阵 `path[i][j]` |
| 路径恢复模块   | 利用 `path[u][v]` 倒推出路径，借助栈或数组恢复正序           |
| 查询输出模块   | 遍历 `m` 对节点，逐对输出路径                                |


##  第三题需求：**Dijkstra 输出最短路径长度**

**任务目标**：给定有向图的邻接矩阵和起点 s，使用 Dijkstra 算法求出从 s 到所有点的最短路径长度。


###  输入说明：

- 整数 `n`：图中点的个数（点编号从 0 到 n-1）
- `n x n` 邻接矩阵（10000 表示无边）
- 一个整数 `s`：起点编号

###  输出说明：

- 输出从起点 s 到所有点的最短路径长度，`n` 行，每行一个点的最短距离。


###  需求分解：

| 模块          | 功能                                     |
| ------------- | ---------------------------------------- |
| 输入模块      | 读取 n，邻接矩阵，起点 s                 |
| 初始化模块    | `dist[s] = 0`，其余为 ∞；`vis[] = false` |
| Dijkstra 主体 | 每次从未访问中选最小的更新周围节点       |
| 输出模块      | 输出 `dist[0]` 到 `dist[n-1]`            |


###  注意事项：

| 点         | 说明                                    |
| ---------- | --------------------------------------- |
| 数据结构   | 最小堆（优先队列）非必需，数组就够用    |
| 无边处理   | 用 `10000` 判断相邻否                   |
| 不可达输出 | 若 `dist[i] >= INF`，也输出原始值或标记 |


##  第四题需求：**Dijkstra 输出路径（路径恢复）**

> **任务目标**：在第三题的基础上，**输出从起点 s 到所有其他节点的最短路径**（路径上的所有节点）


### 输入说明：

同上（图和起点）

### 输出说明：

- 对于每个点 `t`，输出从 `s` 到 `t` 的路径：如 `s t1 t2 ... t`，一行一个。


### 需求分解：

| 模块          | 功能                                            |
| ------------- | ----------------------------------------------- |
| 输入模块      | 同上                                            |
| Dijkstra 主体 | 除了 `dist[]`，还维护 `prev[]` 数组记录路径前驱 |
| 路径恢复模块  | 从目标点 `t` 逆推到起点 `s`，再正序输出路径     |
| 输出模块      | 每一行输出路径（含起点、终点）                  |


### 关键细节：

| 点             | 建议和注意                                   |
| -------------- | -------------------------------------------- |
| prev 初始化    | `prev[i] = -1` 表示没有路径                  |
| 路径恢复方法   | 用递归或栈从 `t` 一直向前走到 `s`            |
| 起点到自身路径 | 输出一个点（比如：`0`）                      |
| 不可达点处理   | 判断 `dist[i] == INF`，输出 `-1` 或 `无路径` |

------

##  Dijkstra 与 Floyd 对比

| 方面             | Dijkstra                 | Floyd                       |
| ---------------- | ------------------------ | --------------------------- |
| 时间复杂度       | O(n²)（堆优化 O(mlogn)） | O(n³)                       |
| 单源 vs 全源     | 单源最短路径             | 任意两点最短路径            |
| 是否支持路径恢复 | 支持（用前驱数组）       | 支持（用 path 矩阵）        |
| 适用图规模       | 稀疏图更优               | 稠密图/所有点对查询场景更好 |


##  建议实现方式

- **数据结构选型**：`dist[]`, `visited[]`, `prev[]`（路径恢复用）
- **结构封装建议**：可以考虑将算法封装成一个类，支持：
  - `run(s)`：运行 Dijkstra 从起点 s
  - `get_path(t)`：从 s 到 t 的路径
  - `get_dist(t)`：从 s 到 t 的距离

```less
main
 ├── array_input       // 输入邻接矩阵
 ├── init_dijkstra     // 初始化 dis 和 vis（算法准备）
 ├── dijkstra          // 执行最短路径计算
 └── result_output     // 输出结果（最短路径）
```



``` less
main
 ├── array_input       // 输入邻接矩阵，初始化 dist 矩阵
 ├── floyd             // 多源最短路径核心算法，更新 arr[][]（dist 矩阵）
 └── 查询循环          // 多组点对查询，输出对应最短路径距离
```
